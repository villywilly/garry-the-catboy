**Use instructions**
_Make sure you have discord.py and dotenv installed on your target server._
1. Set up a discord app on the discord developer portal
2. Clone this repository
3. make a file on your cloned repo called .env
4. Put the following in the env file: TOKEN=Your token from discord dev portal
5. Then run the main script
$ python3 main.py
6. Add the bot to your server by giving it the required permissions in the oauth tab of discord dev portal
7. The bot should work as long as main.py is running. Enjoy!
## A note about the AI model

To use the AI model, you are required to install ollama on the target server you installed this bot to.
